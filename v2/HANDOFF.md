## ۱. وضعیت فعلی — چه کاری انجام شده؟

- **۲۶ فایل پایتون پروژه (~۱۶٬۵۰۰ خط) به‌طور کامل خوانده و درک شد.**
- تحلیل معماری کامل ارائه شد: سه فاز اجرا، لایه‌های core، موتورهای تحلیل، لایه ingestion، دیتابیس.
- روند تصمیم‌گیری Head Agent به‌طور مفصل توضیح داده شد (دو سیگنال قطعی ورودی + چارچوب سه‌حالته + قانون سخت speakers=False + fallback اجرای کامل).
- دو سند دانش ساخته شد: `AGENTS.md` (دانش دائمی پروژه) و همین `HANDOFF.md`.
- **اصلاحات کد (2026-08-16)** — فایل‌های اصلاح‌شده در `fixed_code/`:
  1. `run_phase3.py` — فرمت win_rate (`:.1f%` به‌جای `:.1%`)
  2. `technical_analyzer.py` — پیاده‌سازی واقعی mtf_confluence (HTF_MAP + امتیاز +0.8/−0.8/0/None)
  3. `e2e_news_pipeline.py` — حذف دیتاکلاس‌های مرده و fallback قدیمی؛ تایپ‌های صادقانه
  4. `head_agent.py` — پوشش رویدادهای Medium با ثابت `MARKET_MOVING_IMPACTS` + به‌روزرسانی پرامپت
  5. `phase2_graph.py` + `e2e_news_pipeline.py` — مرتب‌سازی اخبار بر اساس تازگی (tie-breaker: reliability) با `_news_recency_key` قبل از برش top-N/سقف max_items

## ۲. پروژه در یک نگاه

پلتفرم چندعاملی تحلیل بنیادی فارکس با LLM. اصل طلایی: **LLM فقط تفسیر می‌کند؛ امتیازدهی قطعی در پایتون.**
جزئیات کامل معماری، فرمول‌ها، routing، schema دیتابیس و gotchaها در `AGENTS.md` است — آن را حتماً بخوان.

- فاز ۱: سه پایپ‌لاین E2E مستقل (`run.py --mode events|news|speakers`)
- فاز ۲: ارکستراسیون LangGraph + گراف cross-asset (`run_phase2.py`)
- فاز ۳: سیستم چندعاملی Head Agent → Fundamental/Technical → Risk Manager → Trade Memory (`run_phase3.py`)
- LLM پیش‌فرض: Arvan Cloud مدل `GLM-5.2` (env: `ARVAN_BASE_URL`، `ARVAN_API_KEY`)
- دیتابیس: SQLite فایل `crypto_agent.db` با ۹ جدول

## ۳. یافته‌های مهم سشن قبل (که در کد نیست)

1. **پایپ‌لاین سخنران عمداً آفلاین است** (نبود API توییتر/بیانیه‌ها) — هم در پرامپت Head Agent هم با اورراید کد.
2. جهت ذخیره‌شده در DB همیشه currency-native است؛ ترجمه instrument فقط برای نمایش.
3. `get_quick_trend` فقط داده روزانه ۱ ساله می‌بیند — محدودیت طراحی.

## ۵. نحوه شروع سشن جدید با Kimi K3

### روش A — چت وب (kimi.com)
1. فایل‌های `.py` پروژه + `AGENTS.md` + همین `HANDOFF.md` را آپلود کن.
2. پرامپت شروع آماده:

```
این فایل‌ها کل کد پروژه من به‌علاوه دو سند دانش است.
اول AGENTS.md و HANDOFF.md را بخوان و در سطح معماری با کدها تطبیق بده.
نیازی نیست همه ۱۶هزار خط را دوباره خط‌به‌خط بخوانی مگر برای بخشی که روی آن کار می‌کنیم.
بعد بگو آماده‌ای تا تسک بعدی را بدهم.
```

### روش B — Kimi Code CLI
```bash
# فایل‌ها را در ریشه ریپو بگذار (AGENTS.md به‌صورت خودکار خوانده می‌شود)
# یا سشن قبلی را مستقیم ایمپورت کن:
```

### نکته مهم K3
- وقتی مدل را عوض می‌کنی، کش کانتکست باطل می‌شود → **سشن تازه باز کن** (با همین اسناد)؛ هم کیفیت بهتر هم مصرف کمتر.
- K3 تا ۱M توکن کانتکست دارد؛ کل پروژه + اسناد راحت جا می‌شود، ولی برای کار روی یک ماژول فقط همان فایل + AGENTS.md کافی است.
